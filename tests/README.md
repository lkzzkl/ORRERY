# 测试说明

## 一条命令跑全量

```bash
npm test          # 29 条单元测试
npm run smoke     # 页面装配烟雾测试
npm run check     # 单测 + 海报重生成 + 烟雾测试 + 素材校验（交付前跑这条）
```

零第三方依赖，使用 Node 内置 `node:test` 与 `node:assert/strict`。要求 Node >= 18（CI 用 22）。

## 覆盖范围

| 文件 | 用例数 | 覆盖内容 |
|---|---|---|
| `geometry.test.js` | 20 | PRNG 确定性、参数夹取与步长对齐、非法输入回落、哈希敏感性、system 逐字节确定性、坐标边界、密度单调性、离心率、配色回退与对比度、SVG 结构与转义、颜色白名单净化、安全规则正反例、URL 编解码（含坏换码序列） |
| `export.test.js` | 9 | 导出文件名确定性、导出前安全自检、污染调色板净化、导出侧兜底门、分享链接、预设 JSON 往返、描述串 |
| `scripts/smoke.mjs` | 页面级 | 用最小 DOM 桩真实执行 `index.html` 引用的 7 个脚本；除初始化不抛错、预览产出 SVG 外，还**派发真实 `input` / `click` 事件**，验证控件回调、定格、导出、复制链接、保存预设确实生效 |

## 为什么重点测这几类

| 性质 | 对应断言 |
|---|---|
| **确定性** | 同参数 → `deepEqual(system)`、同参数 → 逐字节相同 SVG；这是「产物即作品」与 CI 海报 diff 的基础 |
| **规则显式** | 夹取、步长、单位换算集中在 `PARAM_SPEC` / 纯函数，逐条测边界与越界值，不靠运行时推断 |
| **输入零信任** | URL 与 JSON 预设属外部输入，测 `null` / 空串 / 布尔 / 数组 / 越界 / 坏百分号编码；曾修复 `Number(null) === 0` 被误夹到下界的缺陷 |
| **输出安全** | 生成侧用白名单（`escapeXml()` 转义文本、`color()` 校验颜色、`size` 强制数值），导出侧再以 `inspectSvg()` 兜底；同时测**假阳性**（合法 SVG 不能误报，含 `xmlns` 白名单）与**假阴性**（8 类真实注入样本必须被拦），避免「报全绿」却漏报 |
| **可复现** | `npm run posters` 生成的内置海报在 CI 里被 `git diff --exit-code` 校验 |

## 新增规则时

1. 规则写成纯函数，参数与返回值可序列化。
2. 同时给正例（应通过）与反例（应拒绝/应夹取），只写正例视为未覆盖。
3. 若改动几何或配色，必须同步运行 `npm run posters` 并提交新海报，否则 CI 的 diff 检查会失败。
4. 提交前跑 `npm run check`（单测 + 海报重生成 + 素材校验）。
